vshorts-autopilot

vshorts-autopilot は、YouTube チャンネル 「VTuber構造分析室」 の運営者が、自分のチャンネルの YouTube ショート動画を制作・アップロード・分析するために使う内部ツールです。

vshorts-autopilot is an internal tool used by the operator of the YouTube channel “VTuber構造分析室” to produce, upload and analyze YouTube Shorts for that channel only.

YouTube API Services を使用しています / This app uses YouTube API Services

vshorts-autopilot は YouTube Data API と YouTube Analytics API（YouTube API Services）を使用します。本アプリの利用には YouTube 利用規約 と Google プライバシーポリシー が適用されます。データの取り扱いは プライバシーポリシー / Privacy Policy をご覧ください。

vshorts-autopilot uses YouTube API Services (YouTube Data API and YouTube Analytics API). See our Privacy Policy, the YouTube Terms of Service and the Google Privacy Policy.

利用者について / Who uses this app

このツールは運営者本人のみが使用します。一般向けの登録・ログイン機能はなく、第三者のアカウントにはアクセスしません。

Only the channel operator uses this tool. There is no public sign-up, and it never accesses anyone else’s account.

できること / What it does

  • 運営者のローカル PC 上で、ショート動画（ナレーション・映像）を制作します。
    Produces Shorts (narration and visuals) on the operator’s own computer.
  • YouTube Data API を使い、完成した動画を運営者自身のチャンネルへアップロードし、公開日時を予約します。
    Uploads finished videos to the operator’s own channel and schedules their publication via the YouTube Data API.
  • YouTube Analytics API を使い、運営者自身の動画の成績（再生数・視聴維持率など）を取得し、次の企画の改善に使います。
    Reads performance metrics of the operator’s own videos via the YouTube Analytics API to improve future content.
  • 企画調査のため、YouTube Data API で一般公開されている動画の統計（再生数など）を参照します。
    Looks up public video statistics via the YouTube Data API for content research.
