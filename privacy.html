プライバシーポリシー
Privacy Policy

制定日 / Effective date: 2026-10-06

このプライバシーポリシーは、vshorts-autopilot（以下「本アプリ」）が Google のユーザーデータを含む情報をどのように取得・利用・保存・共有するかを説明するものです。本アプリは、YouTube チャンネル「VTuber構造分析室」の運営者（以下「運営者」）が、自分のチャンネルのためだけに使う内部ツールです。

This Privacy Policy explains how vshorts-autopilot (“the App”) accesses, uses, stores and shares information, including Google user data. The App is an internal tool used solely by the operator of the YouTube channel “VTuber構造分析室” (“the Operator”) for that channel.

1. YouTube API サービスの利用 / Use of YouTube API Services

本アプリは YouTube API サービスを使用しています。本アプリを利用することで、YouTube 利用規約（https://www.youtube.com/t/terms）に同意したものとみなされます。Google によるデータの取り扱いについては Google プライバシーポリシー（http://www.google.com/policies/privacy） をご覧ください。

The App uses YouTube API Services. By using the App you agree to be bound by the YouTube Terms of Service (https://www.youtube.com/t/terms). See the Google Privacy Policy (http://www.google.com/policies/privacy) for how Google handles data.

2. 取得する情報 / Information the App accesses

権限（スコープ） / Scope取得・利用する内容 / What is accessed and why
youtube.upload運営者が制作した動画を、運営者自身のチャンネルへアップロードし、タイトル・説明文・公開日時を設定するためだけに使います。
Used only to upload the Operator’s own videos to the Operator’s own channel and set their title, description and scheduled publish time.
youtube.readonly認証したアカウントのチャンネル名とチャンネル ID を確認し、誤ったチャンネルへのアップロードを防ぎます。アップロードした動画の状態（公開状態・予約日時）を確認します。また、企画調査のため、一般公開されている動画とチャンネルの統計（タイトル、再生数、高評価数、コメント数、登録者数）を参照します。
Used to confirm the channel name and ID of the authorized account (to prevent uploads to the wrong channel), to check the status of uploaded videos, and to look up statistics of publicly available videos and channels (title, views, likes, comments, subscriber counts) for content research.
yt-analytics.readonly運営者自身の動画の成績（再生数、エンゲージビュー、高評価、コメント、共有、登録者の増加、平均視聴時間、平均視聴率、総再生時間）を取得し、今後の企画の改善に使います。
Used to read performance metrics of the Operator’s own videos (views, engaged views, likes, comments, shares, subscribers gained, average view duration, average view percentage, watch time) to improve future content.

本アプリは、第三者の Google アカウントやチャンネルにはアクセスしません。氏名・住所・パスワード・支払い情報などは取得しません。

The App never accesses any third party’s Google account or channel, and does not collect names, addresses, passwords or payment information.

3. 利用目的 / How information is used

  • 運営者のチャンネルへの動画のアップロードと公開予約
    Uploading and scheduling videos on the Operator’s channel.
  • アップロード先チャンネルの確認（誤投稿の防止）
    Verifying the destination channel to prevent mis-uploads.
  • 運営者自身の動画の成績分析と、次の企画の改善
    Analyzing the performance of the Operator’s own videos and improving future content.
  • 公開データを使った企画調査
    Content research using publicly available data.

取得した情報を広告、販売、信用調査、または上記以外の目的に使うことはありません。

Information is never used for advertising, sold, used for credit decisions, or used for any purpose other than those listed above.

4. 保存方法と保存期間 / Storage and retention

  • 保存場所：すべて運営者の個人 PC 内にローカル保存します。本アプリ独自のサーバーやクラウドストレージには保存しません。
    All data is stored locally on the Operator’s personal computer. The App has no server or cloud storage of its own.
  • 認証トークン：OAuth のリフレッシュトークンは、運営者の PC 上のソースコードとは別の場所に保存し、ログには出力しません。
    OAuth refresh tokens are stored on the Operator’s computer, outside the source code, and are never written to logs.
  • 運営者自身の動画の統計：30 日ごとに YouTube API から再取得して更新します。更新できない場合（アクセス権の取り消しなど）は削除します。
    Statistics of the Operator’s own videos are refreshed from the YouTube API at least every 30 days and are deleted if they can no longer be refreshed (e.g. after access is revoked).
  • 公開データ（企画調査用）：他チャンネルの公開動画の統計などは、取得から 30 日以内に削除または再取得します。
    Public data used for research (e.g. statistics of other channels’ public videos) is deleted or refreshed within 30 days of retrieval.

5. 共有 / Sharing

取得した情報を販売・貸与することはありません。共有先は次のとおりです。

  • Google（YouTube）：動画のアップロードとメタデータの設定のために送信します。
    Google (YouTube): to upload videos and set their metadata.
  • AI サービス（Anthropic 社の Claude）：運営者は企画・台本・品質確認に AI を使っています。その過程で、運営者自身の動画の成績の要約や、公開動画の統計が Claude に送信される場合があります。認証トークンやパスワードは送信しません。Anthropic 社による取り扱いは Anthropic のプライバシーポリシー に従います。
    AI service (Anthropic’s Claude): the Operator uses AI for planning, scripting and quality review. In that process, summaries of the Operator’s own video metrics and public video statistics may be sent to Claude. Tokens and passwords are never sent. Anthropic handles such data under the Anthropic Privacy Policy.

上記以外の第三者に提供するのは、法令に基づく開示が求められた場合に限ります。

No other third party receives the information, except where disclosure is required by law.

6. Google API サービスのユーザーデータに関するポリシーの遵守 / Compliance with Google API Services User Data Policy

本アプリによる Google API から取得した情報の利用と他アプリへの移転は、Google API サービスのユーザーデータに関するポリシー（限定使用の要件を含む）に従います。

The App’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. アクセス権の取り消しとデータの削除 / Revoking access and deleting data

本アプリの通常の削除手続きに加えて、Google のセキュリティ設定ページ（https://security.google.com/settings/security/permissions）から、いつでも本アプリのアクセス権を取り消すことができます。

In addition to the App’s normal procedure for deleting stored data, you can revoke the App’s access to your data at any time via the Google security settings page (https://security.google.com/settings/security/permissions).

アクセス権が取り消された場合、または下記の連絡先に削除を依頼された場合、本アプリが保存している API データを 7 日以内に削除します。

If access is revoked, or if deletion is requested via the contact below, the App deletes stored API data within 7 days.

8. セキュリティ / Security

データは運営者の PC 上にのみ保存し、認証情報はソースコード管理（Git）の対象外にしています。ログの出力時には、トークン・パスワードを自動で伏せ字にします。

Data is kept only on the Operator’s computer. Credentials are excluded from version control, and tokens and passwords are automatically redacted from logs.

9. 子どものプライバシー / Children

本アプリは運営者本人のみが使用するツールであり、子どもを対象としたものではありません。

The App is used only by the Operator and is not directed to children.

10. 改定 / Changes

本ポリシーを改定する場合は、このページを更新し、制定日を変更します。

Any changes will be posted on this page with an updated effective date.
